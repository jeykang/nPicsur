# Security

## Supported versions

Security fixes are included in the latest release and the `edge` Docker image, which tracks master.

## Reporting a vulnerability

Use [GitHub’s private vulnerability reporting](https://github.com/jeykang/nPicsur/security/advisories/new). Include reproduction steps and the potential impact. Keep security reports out of public issues.

You can also report issues affecting the unmaintained [original Picsur](https://github.com/CaramelFur/Picsur) here.
