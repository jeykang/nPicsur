# Security

## Supported versions

Security fixes go into the latest release, and the `edge` Docker image that follows the master branch.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through [GitHub's vulnerability reporting](https://github.com/jeykang/nPicsur/security/advisories/new) instead, with the steps to reproduce the problem and what an attacker could do with it.

This is a fork of [Picsur](https://github.com/CaramelFur/Picsur), which is no longer maintained. Problems that also affect the original can be reported here as well.
